# 우리 반 방송국

학생이 작성한 방송 원고를 프롬프터로 읽으며 뉴스 방송을 녹화하는 웹 스튜디오입니다.

## 기능

- 오프닝·앵커·현장 기자·날씨·클로징 큐시트
- 원고 붙여넣기, 자동 스크롤, 글자 크기와 속도 조절
- 카메라 모니터와 원고를 함께 보는 집중 모드
- 방송 화면과 마이크 음성 녹화, 보관함 재생, 기기 공유·저장
- 약 5초의 자체 제작 오프닝 음악·효과음과 녹화 오디오 합성
- 기기 브라우저 내 원고·영상 저장, 큐시트 파일 내보내기·불러오기

## 실행

빌드와 설치가 필요 없는 HTML/CSS/JavaScript 프로젝트입니다. 루트의 파일을 그대로 HTTPS 정적 호스팅에 올리세요.

GitHub Pages: 저장소의 Settings → Pages → Deploy from a branch → main / (root) → Save.

카메라·마이크와 녹화는 HTTPS 또는 localhost에서 사용할 수 있습니다. 아이패드 Safari의 가로 화면을 권장합니다.

자세한 사용법과 검증 범위는 [사용안내](사용안내.md)를 참고하세요.

## 개인정보

원고, 카메라, 마이크, 영상은 외부 서버로 전송하지 않습니다. 녹화 영상은 브라우저의 IndexedDB에 보관되며, 완성 영상은 기기에 별도로 저장하세요.
